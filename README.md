# handy-macOS-apps
Welcome to this repo!
Here I make small but handy apps for macOS, including QuickScreenSettings, FinderViewOptimiser, NotificationTimer and more!

The apps are mainly tested on macOS 11 but should be compatible with newer macOS and older OSX versions. I have a small group of testers with newer versions of MacOS, but until I aquire a new Mac, any feedback is much appreciated.

Usually, installation for .app files involves moving them to the applications folder after unzipping them but workflows should install quite straightforwardly.
